================================================================================
アンギオ（XA）計測 — 実践的な操作例
GRAPHY-Next / 2026-08-25 作成
================================================================================

この文書は「いま入っている機能で、実際にどう操作すると数値が出るのか」を手順として
書いたもの。設計と実装状況の正本は fw/angio-design.md（この文書は操作面だけを抜き出した
副本）。画面のラベルは frontend/src/i18n/ja.ts の実文言をそのまま使っている。

前提
  - standalone（Electron 版）で確認した手順。web モードは XA 未対応（A12・未着手）。
  - すべての解析は「研究用（Research Use Only）」。単独で診断に用いない。
  - 対象は XA / XRF のマルチフレーム（シネ）シリーズ。単一フレームの静止画では
    解析ボタン自体が出ない（フレーム軸を持つスタックのときだけ出る）。


================================================================================
0. 画面のどこに何があるか
================================================================================

メイン画面
  機能メニュー ＞ 解析タスク ............ 何ができるかの一覧（押せない理由も出る）
  機能メニュー ＞ 被ばく線量レポート（RDSR）
  機能メニュー ＞ レポート .............. 解析結果の差し込み先
  画像メニュー ＞ 2D Viewer ............. シリーズを選んでから開く

2D ビューア（シリーズビュー）
  画像の下 ........ シネコントロール（再生 / 一時停止 / ループ / 速度 / fps の根拠）
  その下の操作列 .. DSA（サブトラクション）｜校正 / QCA｜QVA｜LV 解析｜3D QCA｜
                    3D 分岐部｜表示状態を適用｜MP4｜フレームを PNG で保存
  ROI メニュー .... 「長さ」← 解析の入力はすべてこの計測から始まる

各ダイアログの右端
  「解析の段」（ステップ・レール）
     ✓ 済 ／ ▶ 実施中 ／ ○ 未 ／ ⤼ 飛ばした ／ ✕ 不可
     「この段へ移動」＝画面をその段までスクロール
     「この段からやり直す」＝その段の手修正（と意味を失う後続の手修正）だけを捨てて再解析
     ⤼「飛ばした」は「済」ではない。校正を飛ばすと px のまま結果が出る。

押せないボタンの理由（ツールチップに出る）
  LV 解析 ....... フレームが 3 枚未満だと押せない
  3D QCA / 3D 分岐部 ... 2D QCA を 2 方向ぶん実行するまで押せない


================================================================================
1. 例1 — 冠動脈 1 枝の狭窄を測る（2D QCA）
================================================================================

所要: 慣れれば 1 病変あたり 1〜2 分。

 1) メイン画面で XA のシリーズを選び、画像メニュー ＞ 2D Viewer で開く。

 2) シネを再生し、造影が最も濃く、対象枝が最も伸びて見える（＝短縮の少ない）
    フレームで止める。ホイールは 1 ノッチ＝1 フレーム、テンキー 8 / 2 でも 1 枚ずつ動く。
    🔴 この 1 枚の選び方が結果に一番効く。重なりと短縮のあるフレームで測ると、
       あとの手修正では取り返せない。

 3) 校正する。
    a. ROI メニュー ＞「長さ」を選ぶ。
    b. カテーテル（造影されていない部分が望ましい）の**外径をまたぐように**線を引く。
       ＝ 血管の走行に沿ってではなく、直交してカテーテルの幅を横切る。
    c. 「校正 / QCA」を開く →「空間校正」の「カテーテル外径 (Fr)」に 6 などを入れ、
       「カテーテルで校正」。
       ※ 引いた線の長さがそのまま既知寸法として扱われる（＝線の引き方がそのまま精度）。
       ※ Fr → mm は 1Fr = 1/3 mm の定義計算。実測外径は製品差があるので「公称値による」。
    d. ルーラーやマーカーを使うなら「既知の長さ (mm)」に実寸を入れて「この長さで校正」。
    → 校正はシリーズ単位で保存され、次に開いても残る。解除も残る。
    → 上部の「空間校正: …」に出自（カテーテル法／DICOM PixelSpacing (FIDUCIAL)／
      幾何近似 など）が出る。⚠ 付きは近似。未校正なら数値は px で出る。

 4) 解析区間を指定する。
    「長さ」ツールで、病変の**近位の健常部 → 遠位の健常部**へ 1 本引く。
    （病変だけをまたぐのではなく、両端に健常部を含める。参照径をここから当てはめるため）

 5) 「校正 / QCA」の「入力（長さ計測）」で今引いた線（#2 など）を選び、「解析する」。

 6) 出る数値
       MLD ..................... 最小血管径
       RVD ..................... 参照径
       % Diameter Stenosis ..... 直径狭窄率
       % Area Stenosis ......... 面積狭窄率（円形断面の仮定）
       病変長 / 計測点数
       径プロファイル（実線＝計測径、破線＝参照径、点＝MLD）
    数値の下に「径は密度計測で測っています」または「半値法で測っています」が出る。
    ここは必ず読む（→ 第 8 章）。

 7) 中心線とエッジを目で確かめる。
    🔴 自動の中心線は血管から外れていても**必ず結果を出す**。外れたまま保存できてしまう。
    ずれていたら第 2 章へ。

 8) 保存（第 7 章）。

解析に使った「長さ」計測は自動でロックされる（🔒）。線が動いて結果とずれないため、
また分岐部のように同じ端点から次の区間を引くときに、既存の線を掴まずに新しい線を
引けるようにするため。引き直したいときは「ロック解除」。

2. 例2 — 自動が外れたときに人が直す（QCA 手修正）
================================================================================

直す順番は必ず 中心線 → エッジ → 区間・参照径。中心線を動かすとエッジ修正は
破棄される（別の場所に当たってしまうため。⚠ が出る）。

 (A) 中心線が血管から外れている
     「手修正」→「中心線（通過点）」
       クリック ....... 通過点を追加
       ドラッグ ....... 通過点を移動
       右クリック（または Alt＋クリック） ... 削除
     通過点の間は画像に沿って引き直される。1〜2 点で足りることが多い。

 (B) エッジが枝や重なりに引っ張られている
     「手修正」→「エッジ」
     エッジ点をドラッグ。断面の意味を保つため、法線方向にしか動かない。

 (C) 解析区間に分岐や造影の切れ目が入ってしまった
     グラフ操作 →「区間を切り詰め」→ グラフを横にドラッグ。
     解除は「切り詰めを解除」。

 (D) 参照径の当てはめが外れている（先細りが強い、区間の大半が病変）
     グラフ操作 →「健常部を指定」→ グラフを横にドラッグ。
       1 区間だけ指定 ... 参照径はその平均（一定）
       2 区間以上 ....... 区間の間を直線で結ぶ（先細りを表現できる）
     解除は「健常部の指定を解除」。

 (E) 全部やり直す
     「手修正をすべて破棄」。あるいは右の段の「この段からやり直す」。

手修正が入ると「✋ 手修正あり — 通過点 n / エッジ n 点 / 切り詰め / 参照径」が出る。
この表示は保存する SR にもレポートにも残る（＝自動値ではないことが受け手に伝わる）。

3. 例3 — DSA を作ってから測る（末梢・脳血管）
================================================================================

骨や腸管ガスが重なって自動追跡が外れる場合、先に差分してから測ると通ることが多い。

 1) 「DSA（サブトラクション）」にチェック。
    マスク（造影前フレーム）は DICOM の Mask Subtraction Module があればそれに従う。

 2) マスクを選び直す ...... 造影前の落ち着いたフレームを表示して
                            「現在フレームをマスクに」。

 3) 体動を補正する ........ 「自動位置合わせ」（背景の残差が最小になるシフトをサブピクセルで
                            探す）。うまくいかなければ「1 px ずらす」で手動。
                            「背景残差」の数値が小さいほど合っている。

 4) 必要なら「対数変換」。

 5) そのまま「校正 / QCA」または「QVA」を実行する。
    表示中の合成画像がそのまま解析対象になり、差分後は血管が正の大きな値として扱われる
    （見た目の白黒とは別に、内部の極性は正しく切り替わる）。

⚠ 既知の持ち越し（fw/angio-design.md §6.6.1）
   DSA 合成画像は素直な VOI の対応の**逆**に描かれている。画面では血管が暗く見え、
   古典的な DSA の見え方なので実用上は困らないが、意図してそうなっているわけではない。
   数値には影響しない。

4. 例4 — 末梢・脳動脈の瘤を測る（QVA）
================================================================================

QCA と同じダイアログの別モード。違いは参照径の決め方と、瘤の指標が出ること。

 1) 校正する（QCA と同じ。脳血管ではルーラー法を使うことが多い）。
 2) 「長さ」ツールで 瘤の近位の健常部 → 遠位の健常部 へ 1 本引く。
 3) 「QVA」を開き、入力を選んで「解析する」。

 出る数値
    最大径 ／ 参照径 ／ 拡張比（○○ ×、○○ %）
    拡張長 ／ ネック径（近位 / 遠位）
    偏心度（0.5 以上で「嚢状」、未満で「紡錘状」）
    判定 — 「動脈瘤（参照径の基準以上）」／「拡張はあるが動脈瘤の基準未満」
           必ず基準（参照径の何倍以上を瘤とするか）が併記される。

 参照径は解析区間の**両端**から決まる（瘤が区間の大半を占めても参照径が動かないため）。
 外れていればグラフで「健常部を指定」して上書きする。

⚠ 1 方向の投影による計測。見えている向きでの最大径であって、瘤そのものの最大径とは
  限らない。3D-RA の瘤検出プラグインとは別の機能。
🔴 拡張比（最大径 ÷ 参照径）は狭窄率と違って半値法の系統誤差が打ち消されない
  （太さの違う 2 点を比べているため）。第 8 章を読むこと。

5. 例5 — 左室造影で EF を出す（QLV・単一面）
================================================================================

前提: 単一面 RAO 30° の左室造影。フレームが 3 枚以上必要。

 1) 左室造影のシリーズを 2D ビューアで開く。
 2) 「LV 解析」を開く。造影面積の時系列から ED / ES が自動提案される
    （緑＝ED、橙＝ES）。
 3) 提案を必ず目で確かめる。外れていたら
      「提案し直す」 .................. もう一度自動提案
      「輪郭の範囲で提案し直す」 ...... ED 輪郭の外接矩形の中だけで数え直す
         ← 画面全体で数えると横隔膜・脊椎・カテーテル・大動脈を拾ってしまう。
            これが効く場面は多い。
      ED / ES のフレーム番号を直接指定してもよい。
    🔴 造影剤注入で心室期外収縮が起きることがあり、その直後の心拍は EF を過大評価する。
    ⚠ 「ED → ES の間隔が生理的にありえません」等の警告が出たら、必ず手で選び直す。
 4) 「ED を引く」→ 大動脈弁輪の一端 → 心尖 → 他端 の順にクリック。
    （最初と最後の点を結ぶ弦が弁面になり、そこから長軸が決まる）
    点はドラッグで移動、右クリック（Alt＋クリック）で削除、線の途中をクリックで挿入。
    4 点以上必要。
 5) 「ES を引く」で同様に。同じ弁面を指すこと（ED と ES で弁輪の幅が大きく違うと警告）。
 6) 結果
      駆出率 (EF) ／ EDV ／ ESV ／ Kennedy 補正
      壁運動（弧長で対応付けた弦の短縮・無次元。Sheehan の centerline 法ではない。
              正常値データベースは持たないので正常・異常の判定はしない）
    ⚠ 未校正でも EF は正しい（スケール不変）。容積 (mL) と Kennedy 補正だけが出ない。
    ⚠ Area-Length 法（単一面）は左室を回転楕円体と仮定する。心尖部瘤・著しい変形では
      誤差が大きい。

バイプレーン（Simpson 法）は未実装（A5c・検証データ待ち）。

6. 例6 — 2 方向から 3D で測る（3D QCA）
================================================================================

短縮の影響を受けない長さと、断面積を出す。

 1) 方向 A のシリーズを 2D ビューアで開き、第 1 章のとおり 2D QCA を最後まで実行する。
 2) 方向 B のシリーズを開き、**同じ区間**（同じ始点から同じ終点まで）で 2D QCA を実行する。
    2D ビューアはシリーズごとに別ウィンドウで開くが、実行済みの方向は
    ウィンドウを跨いで共有される。
    ⚠ セッション限り。全ウィンドウを閉じると登録は消える（永続化していない）。
 3) どちらかのウィンドウで「3D QCA」を開く。
    「方向 A」「方向 B」に、QCA 済みで角度・SID/SOD が読めた方向だけが並ぶ。
 4) 視線の角度差を見る。30° 未満だと奥行きが決まらないので結果を出せない。
 5) アンカーを取る。
    左の中心線で点を選び、続けて右で同じ場所を選ぶと 1 組になる。
    分岐部・ステント端など、両方向で同定できる点を使う。
    端点 2 つは常にアンカー。
    🔴 アンカーが 3 点以上ないと装置の角度誤差を補正できない（2 点では残差が必ず 0 に
       なり、補正が退化する）。実務では最低 1 点は追加する。
 6) 「再構成する」。

 出る数値
    3D 長さ ／ 直径狭窄率（3D）／ 面積狭窄率（3D）／ 病変長
    最小断面積 ／ 最小等価直径
    アンカーの再投影誤差 ／ 角度補正の適用有無
    見えている長さの割合（短縮）と、短縮が少ない撮影角度の候補
    3D 中心線のプレビュー（ドラッグで回転。「3D ビューアで開く」で別窓に出せる）

 読むときの注意
  🔴 「対応付けの再投影誤差」は幾何の正しさの指標にならない（角度が数度狂っていても
     小さいまま出る）。判定に使うのは**アンカーの**再投影誤差。
  🔴 血管が視線方向に潰れている（短縮が強い）と、自動追跡が弧長を取りこぼして
     長さが系統的に短く出る。対策は短縮の少ない 2 方向で撮り直すことだけ。
  ⚠ 長さ・狭窄率のように向きに依らない量は正しく出るが、患者座標系での向きは
     復元されない（方向 A を基準に固定するため）。
  ⚠ 2 方向が別の心拍なら、心位相の一致は近似。
  ⚠ 断面は「楕円の主軸が 2 方向の測定方向に一致する」という仮定で合成している。
     2 方向が直交から離れるほどこの仮定の影響が大きい。
  🔴 2 方向で径の測り方が違う（半値法と密度計測）と、合成した断面積はどちらの意味でも
     なくなる。その場合は絶対値を使わず狭窄率（比）で見る。

 品質基準を満たさない結果は保存できない（保存ボタンが押せない）。

7. 例7 — 分岐部を測る（3D QCA 分岐部）
================================================================================

 1) 近位母血管・遠位母血管・側枝の 3 本を、それぞれ 2 方向ぶん 2D QCA する（計 6 回）。
    同じフレームから 3 本の区間を引くことになる。解析済みの線はロックされるので、
    同じ端点から次の区間を引ける。
 2) 「3D 分岐部」を開き、各枝に方向を割り当てて「分岐部を解析」。

 出る数値
    枝ごとの病変長・除外長
    分岐角（遠位↔側枝）／近位↔側枝／近位↔遠位
    Finet / Murray の経験則との差（参考値。径の推定には使っていない）
    分岐部が重ならずに見える撮影角度の候補（3 つ・角度差 15° 以上）
      例: LAO 35° / CRA 25°（見えている割合 82%・重なり 1.2mm・遠位母血管↔側枝）
      → ステントを置く前に「どの角度で撮ると分岐が見えるか」を数値で選べる。
      🔴 3 本の中心線と径だけから計算した見積り。**他の血管・脊椎・カテーテル・
         横隔膜との重なりは入っていない**。装置の可動範囲・寝台・術者の立ち位置も見ていない。
      ⚠ 径を出せない枝があると、重なりは中心線どうしで判定する（その旨が画面に出る）。
         実際はもっと重なる。

 注意
  - カリーナから母血管 1 径ぶんの範囲は「内腔が 2 本に分かれていて径が定義できない」ので
    測らない（除外長として出る）。
  - この画面では枝ごとの手動アンカーを取らない（端点のみ対応付け）。厳密に見たい枝は
    単一血管の 3D QCA で個別に解析する。
  - Medina 分類は自動では出さない（%DS 50% の境界で分類が跳ぶため）。3 本の %DS から
    判断する。
  - 「カリーナ側の径が母血管より太い」という警告が出たら、投影で母血管と重なった区間を
    測っている可能性が高い。その枝の径・分岐角・Finet/Murray との差はいずれも信用しない。


================================================================================
8. 数値を読むときの約束（ここを外すと結論を間違える）
================================================================================

(1) 報告する径は「密度計測」で出している
    −ln T の横積分（＝ μ×断面積）から径を出す方式。病変部の断面の形を仮定しない。
    ただし基準の減弱係数 μ を健常部から求めるので、**健常部は円形と仮定している**。
    散乱・重なった血管・強いノイズがあると過大に出ることがある。
    ノイズが大きい・参照径が決まらない等の場合は自動で半値法に退避し、その理由が
    画面に出る。

(2) 画面の輪郭線は常に半値法
    密度計測は径を返すが輪郭を返さない。したがって**線は目安、数値は密度計測**。
    線と数値が食い違って見えても不整合ではない。

(3) 「径は 13% 過小」を定数として持ち回らない
    半値法の係数は断面の形で 0.745〜0.918 まで動く。0.870 は円柱に固有の値。
    内腔がぼけ幅以下だと符号が反転して過大にもなる。

(4) 比なら打ち消される／打ち消されない
    %DS（狭窄率） ..... 同じ断面の比なので系統誤差はほぼ打ち消される
    拡張比（QVA） ..... 太さの違う 2 点の比なので**打ち消されない**
    MLD / RVD の絶対値 ... 打ち消されない

(5) 単一投影の限界
    面積狭窄率は円形断面の仮定。偏心性病変では IVUS/OCT の実測と乖離する。
    短縮と重なりの影響も受ける。3D QCA はここを改善するためにある。

(6) 未校正なら px
    「未校正のため px 単位です」が出ている状態の数値を mm として読まない。

9. 保存・書き出し・レポート
================================================================================

「校正 / QCA」ダイアログの「保存」
   表示状態を保存 (GSPS)
     DSA のマスク・ピクセルシフト・VOI・空間校正・QCA の描画を保存する。
     元画像は変更しない（非破壊）。
   計測値を保存 (SR)
     MLD / RVD / %DS / 病変長 と、校正の出自・手修正の有無を残す。

保存した表示状態を読み戻す
   2D ビューアの「表示状態を適用」。
   この画像を参照している GSPS だけが一覧に出る。適用前に
   「適用されるもの／適用されないもの」が明示される（LUT で書かれた階調、
   Presentation LUT、表示シャッターなどは当てない）。他社が書いた GSPS も読める。

画像として出す
   MP4 .................. 表示中のシネを画面と同じ絵・同じ再生速度で書き出す
                          （ffmpeg が必要。無ければ 422 で「PNG を使え」と出る）
   フレームを PNG で保存 .. 表示中のフレーム列を ZIP で書き出す（DSA 表示中は差分画像）
   ⚠ どちらも書き出し前に確認が出る。PNG に DICOM タグは含まれないが、
     **画像に焼き込まれた患者情報（バーンドイン注釈）は消えない**。

レポートへ差し込む
   メイン画面 ＞ 機能 ＞ レポート を開き、「解析結果を差し込む」。
   QCA / QVA / QLV / 3D QCA の結果が、値と一緒に
     出自（空間校正・手修正の有無・ED/ES の決め方・アンカー数・角度補正の有無・短縮）
     と限界（研究用である旨・径の測り方・未校正・Area-Length の仮定 など）
   ごと本文へ入る。数値だけを貼らないための作り。
   ⚠ 差し込める結果はセッション限り・直近 20 件まで。メインウィンドウを閉じると消える。

10. うまくいかないとき
================================================================================

解析ボタンが出ない
   → XA / XRF のマルチフレームではない。単一フレームの静止画には出ない。

「先に「長さ」ツールで線を引いてください」
   → ROI メニュー ＞ 長さ で線を引いてから開く。校正なら既知寸法の上、
      QCA なら解析区間の始点→終点。

「解析できませんでした（中心線を引けない／エッジが検出できない）」
   → 区間が短すぎる／造影が薄い／背景が強い。フレームを変える、DSA を掛ける、
      区間を引き直す。

数値が px で出る
   → 未校正。カテーテル法かルーラー法で校正する。装置の PixelSpacing が
      ImagerPixelSpacing と同値のときは規格上「未補正」なので px 表示になる（正しい挙動）。

「LV 解析」が押せない
   → フレームが 3 枚未満。

「3D QCA」「3D 分岐部」が押せない
   → 2D QCA が 2 方向ぶん済んでいない。または角度・SID/SOD が読めなかった方向しかない。
      ウィンドウを全部閉じると登録が消えるので、その場合はやり直す。

3D の結果が保存できない
   → 品質基準（角度差・アンカー再投影誤差など）を満たしていない。理由が段に出ている。

EF は出るが容積 (mL) が出ない
   → 未校正。EF はスケール不変なので校正が無くても正しい。

DSA の背景が動いて見える
   → 「自動位置合わせ」→ それでも残るなら「1 px ずらす」で追い込む。
      「背景残差」を目安にする。

MP4 が失敗する
   → ffmpeg が無い。連番 PNG はそのまま使える。
