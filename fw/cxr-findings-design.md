# 胸部 X 線の所見検出（研究版）設計

> 記録開始 2026-10-06。2026-10-05 にユーザが TODO に加えた（`fw/ct-quant-design.md` §9）。**研究用（非医療機器）**。
> 所見の「確率」と「どこを見たか（ヒートマップ）」を出すだけで、診断・トリアージ・読影の代わりはしない。

## 0. 要約

- 公式プラグイン **`vis-cxr-findings`（「胸部 X 線の所見」）**。`category: "ai"` で「解析 ＞ AI」に 1 項目。
- モデルは **TorchXRayVision の `densenet121-res224-nih`**（NIH ChestX-ray14 だけで学習・14 所見）を主にし、肺炎・肺の陰影だけ **`densenet121-res224-rsna`** を足す。外部の計算機（Colab）で動かす（H59・匿名化・同意・監査）。
- 位置は **Grad-CAM のヒートマップ**を計算機の上で作って返し、プラグインの窓で画像に重ねる。枠（bounding box）は出さない。
- 心胸郭比（CTR）は v1 では出さない（§1.3）。

## 1. モデルとライセンス（2026-10-06 調査）

調査はサブエージェントに任せ、要の 2 点だけを原典で確かめた（下の ✔）。ほかは調査の報告（出典 URL つき）によるもので、採用前に取り直す。

### 1.1 採用するもの

| モデル | 出力 | コード | 重み | 学習データとその条件 |
|---|---|---|---|---|
| TorchXRayVision `densenet121-res224-nih` | 14 所見の確率（224 px） | Apache-2.0。✔ LICENSE の冒頭は「Licenses vary by subpackage」で、Apache-2.0 の対象に `xrv.models` などを挙げる（2026-10-06・GitHub API で確認） | **記載なし**（GitHub release v1 で配布） | NIH ChestX-ray14。✔「There are no restrictions on the use of the NIH chest x-ray images」（Google Cloud の NIH データのページ・2026-10-06 確認）。条件は出典の表示・論文の引用・謝辞 |
| TorchXRayVision `densenet121-res224-rsna` | 肺炎・Lung Opacity | 同上 | 記載なし | RSNA Pneumonia（NIH の画像に注釈を足したもの）。利用規約は商用・非商用を明記して許す（調査の報告・RSNA の PDF） |

- ⚠ **重みのライセンスが明示されていない**。研究版で使うのは問題が小さいと判断するが、SaMD 化の前に作者（mlmed）に書面で確かめる。
- NIH のラベルは読影レポートから自動抽出したもの（誤りを含む）。確率の意味もそれに引きずられる。

### 1.2 使わないもの（営利企業の配布物として問題があるもの）

- CheXpert・MIMIC-CXR・PadChest・VinDr-CXR を含む重み（XRV の `-all`・`-chex`・`-mimic_*`・`-pc`・`resnet50-res512-all`、JF Healthcare）。CheXpert は商用不可、MIMIC・VinDr は PhysioNet の資格制で研究のみ、**PadChest は 8 条で生成物を診療に使うことを禁止**。
- Microsoft MAIRA-2（MSRLA：非商用・再配布もホスティングも禁止）、BiomedCLIP・RAD-DINO（MIT だが「研究目的のみ／臨床不可」と表示）、CXAS（CC BY-NC-SA）。
- Google CXR Foundation（HAI-DEF 規約。商用は禁じないが、下流の利用者への使用制限の伝達・規制当局の承認・Google を製造者にしない条件がある）。v1 では使わない。
- 補足（2026-10-06 のユーザ判断について）: 「研究版はオープンソースなので使ってよい」は、ライセンスが CC BY などのデータには当てはまる。非商用・研究のみの条件は**使う人と目的**に掛かる（コードが OSS かどうかでは外れない）ので、上の除外は維持する。

### 1.3 心胸郭比（CTR）

肺野・心臓のマスクを出す既製のモデルで、ライセンスが問題なく使えるものは見つからなかった（XRV の PSPNet は学習データの出所を作者も把握していない（issue #158）、ianpan のモデルは CheXpert で学習、CXAS は NC、HybridGNet は GPL-3.0）。NIH の画像（制限なし）と CheXmask のマスク（CC BY 4.0）で自社で学習する案がある（CheXmask を作った HybridGNet の学習データの条件は未確認）。v1 では出さない。

## 2. 入力（本体の側で要ること）

- 外部の計算機へは本体が作る npz（`VolumeAssembler`）で送る。DX/CR の 1 枚でも作れる（患者座標が無ければ NaN、グレースケールだけ）。値は Rescale 適用済み、`meta.json` に PhotometricInterpretation が入る。
- **足りないもの: 表示の窓（WindowCenter/Width・VOI LUT・VOILUTFunction）**。胸部 X 線のモデルは表示に近い 8 bit 相当の画像で学習しているので、生の値を最大値で割るだけでは学習時と見え方がずれる（どれだけ効くかは実画像で確かめる）。→ **C1 で `meta.json` に VOI を足す**（本体の変更・後方互換）。
- MONOCHROME1（白黒が反転）は計算機の上で反転してから入れる。
- 焼き込みの文字（患者名など）は既存の `RemoteBurnPolicy` が扱う（送る前に止める・塗る）。

## 3. 計算機の上

1. `pip install torchxrayvision==<固定>`（版は C2 で決める）。
2. npz → 2D 画像。MONOCHROME1 なら反転、VOI の窓で 8 bit 相当にしてから、TorchXRayVision の正規化（[-1024, 1024]）・中央の切り出し・224 px。
3. `nih` と `rsna` の重みで推論。所見ごとの確率。
4. 確率が高い所見から順に Grad-CAM（最後の畳み込み層）を作り、元の画像の大きさに戻して返す。何個作るかは画面で選ぶ（既定は上位 3）。
5. 返すもの: `findings.json`（所見名・確率・モデル・版）と `cam_<所見>.npy`（float32・元の画像と同じ大きさ）。

## 4. 画面と保存

- 一覧: 所見・確率（2 つのモデルの所見は別の行。同じ名前でも混ぜない）。**閾値で「あり・なし」を出さない**（確率の較正はこのデータでは確かめていない）。
- 行を押すと、その所見のヒートマップを窓の中の画像に重ねる（ビューアの画像は変えない）。
- 保存: CSV（所見・確率・モデル）、SR（所見の文として。確率を入れる計測の種別は SR の表に無いので、v1 は文に書く）、ヒートマップは派生シリーズ（H4b）で保存できるようにする（任意）。

## 5. 検証

| 何を | どう | 合格の基準 |
|---|---|---|
| 前処理 | 既知の画像で、計算機の上の前処理（反転・窓・切り出し）を TorchXRayVision の手順と比べる | 一致 |
| 経路 | 同じ画像を、GRAPHY を通した場合と、TorchXRayVision に直接かけた場合で比べる | 確率が一致（同じモデル・同じ入力） |
| 実機 | 公開の胸部 X 線を DICOM（DX）にして取り込み、Colab で通す | 実行・一覧・重ね表示・保存。重ね表示はスクリーンショットで判定 |
| 精度の参考値 | **学習に使われていない**公開データ | データとライセンスの確認から（NIH・RSNA は学習データそのものなので使えない。VinDr は研究のみ、JSRT は営利の扱いが未確認） |
