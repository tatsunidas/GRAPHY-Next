# キーボードショートカット

> 作成日: 2026-06-28
> このファイルが**正本**。実装の単一ソースは `frontend/src/shortcuts/registry.ts`。
> アプリ内ヘルプ（`?` キー、または ⌨ ボタン）も同レジストリから生成される。
> 追加・変更時は**本ファイルとレジストリを必ず同時更新**する。
>
> `Mod` = Windows/Linux は **Ctrl**、macOS は **Cmd(⌘)**。
> **文脈依存**: 有効な Window/Dialog によって挙動を切り替える（例: `Esc` はダイアログが開いていれば閉じ、
> ビューアでは表示リセット）。入力欄フォーカス中は `Esc` 以外のショートカットを無効化する。

## グローバル（実装済み）
| キー | 動作 |
|---|---|
| `Mod + ,` | 環境設定を開く |
| `Mod + Shift + D` | DB テーブル管理を開く（standalone のみ） |
| `?` | キーボードショートカット一覧 |
| `Esc` | ダイアログを閉じる |

## ツール（将来・予約：2D ビューア実装時に配線）
| キー | 動作 |
|---|---|
| `W` | Window/Level（階調調整。ドラッグで明るさ/コントラスト） |
| `P` | Pan（移動） |
| `Z` | Zoom（拡大縮小） |
| `L` | Length（2点間の距離計測） |
| `A` | Angle（3点の角度計測） |
| `R` | ROI 矩形（Rectangle） |
| `E` | ROI 楕円（Ellipse） |

## 画像ナビゲーション
| キー | 動作 | 状態 |
|---|---|---|
| `↓` / `↑`、**テンキー `2` / `8`** | 次 / 前のスライス（**1 打鍵 = 1 スライス**） | 実装済み |
| `→` / `←` | 次 / 前のシリーズ | 予約（ハンドラ未登録） |
| `Space` | シネ再生 / 停止 | 実装済み（シリーズビューのみ） |
| `Home` / `End` | 最初 / 最後のスライス | 実装済み（シリーズビューのみ） |

### テンキー（2026-08-25）

🔴 **テンキーは `e.key` だけでは判定できない。** NumLock が入っていると `e.key` は `"8"`（ただの数字）、
切っていると `"ArrowUp"` になるので、`combo`（＝`e.key` 判定）だけだと**NumLock の状態で効いたり
効かなかったりする**。そこで `ShortcutDef.codes`（`e.code` ＝物理キー）を足し、
`matchesShortcut(id, e)` が **combo または codes** で一致を見る。

- `nav-prev-slice`: `ArrowUp` ＋ `Numpad8` ／ `nav-next-slice`: `ArrowDown` ＋ `Numpad2`
- ⚠️ **`codes` は修飾キーが 1 つも押されていないときだけ一致させる**。物理キーは配列に依らず
  素通しするので、`Ctrl+Numpad8` まで拾うと他の割り当てと衝突する。
- 一覧（`KeyboardHelp`）は `displayShortcut()` で `↑ / Num 8` と併記する。
- テスト `shortcuts/registry.test.ts`（NumLock ON/OFF・上下の取り違え・`Digit8` を拾わないこと）。

### どの画面で効くか

| 画面 | スライス送りの実体 | ↑↓・テンキー |
|---|---|---|
| シリーズビュー（2D） | React state `z`（唯一の出所） | ✅ |
| MPR 3 面 | Cornerstone のボリューム面 | ✅（面をクリックしてフォーカス） |
| Slicer 直交 3 面 | **自前描画のパネル**（法線方向に最小 voxel 間隔で center を動かす） | ✅（同上） |
| Slicer 再構成プレビュー | Cornerstone のスタック | ✅（同上） |

⚠️ **MPR / Slicer は面をクリックしてフォーカスを当ててから**効く（各面 `tabIndex={0}`）。
Cornerstone のツールはキーボードを受けないので、キー送りは `utilities.scroll` を直接叩く
（`viewer/sliceStep.ts`）。ホイールの経路（`StackScrollTool`）とは独立。
