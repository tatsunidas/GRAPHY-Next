## ROI を「作る → 動かす → 形を変える」で続けて操作する（PR #224・2026-10-07）

**利用者に伝えること**: ROI を描いたあと、そのまま内側をドラッグして動かせるようになった。
以前は内側をドラッグすると新しい ROI ができてしまっていた。

| 操作 | 結果 |
|---|---|
| ROI を描き終える | その ROI が選択される（緑） |
| 選択中の ROI（矩形・楕円・ポリゴン・フリーハンド）の内側をドラッグ | ROI が移動する |
| 角のハンドル・輪郭線をドラッグ | 形が変わる（従来どおり） |
| Esc | 選択を外す。外すと、その ROI の内側に別の ROI を新しく描ける（臓器の中に病変など） |
| フリーハンドの統計の文字ボックスをドラッグ | 文字ボックスが動く（以前は何も起きなかった） |

- 内側で動くのは、ROI ツールを選んでいるときだけ。W/L・Pan のときは、ROI の上でも W/L・Pan が効く。
- 撮る画面の案: ①矩形を描いた直後（緑＝選択中）②内側をドラッグして動かした後 ③Esc のあと内側に小さい ROI を描いた入れ子（外が黄色、内が緑）。
  実機スパイク `automator/src/spike/roiMoveCheck.ts` の `rect-created` / `rect-moved` / `rect-nested` と同じ構図でよい。

## ROI の複数選択とまとめて移動（PR #226・2026-10-07）

**利用者に伝えること**: Ctrl（Mac は ⌘）＋クリックで ROI を複数選択し、まとめて動かせるようになった。

| 操作 | 結果 |
|---|---|
| 画像上の ROI を Ctrl/⌘＋クリック（線でも内側でも） | 選択に足す・外す |
| ROI マネージャの行を Ctrl/⌘＋クリック | 選択に足す・外す（スライスは移動しない） |
| 選択中の ROI のどれかをドラッグ | 表示中のスライスにある選択中の ROI がすべて同じ量だけ動く（長さ・角度などの計測も含む） |
| ハンドルをドラッグ | 掴んだ ROI だけ形が変わる。複数選択はそのまま |

- 注意として書くこと:
  - 別のスライスで選択した ROI は動かない（見えない ROI が動くのを防ぐため）。
  - 元に戻す（Ctrl+Z）は ROI の移動を戻さない（表示の操作だけが対象。以前から同じ）。
- 撮る画面の案: ①同じスライスに矩形 2 つと楕円 1 つ。矩形 2 つを Ctrl＋クリックで選択（緑 2・黄 1）
  ②矩形を 1 つドラッグして 2 つが一緒に動いた後（楕円は元の位置）。スパイクの `multi-moved` と同じ構図。
- ⚠ Mac の ⌘＋クリックは実機で確かめていない。ガイドに載せる前に Mac で一度押す。

## DB フォルダの切り替え（デスクトップ版・2026-10-11）

**利用者に伝えること**: 検査の索引と DICOM ファイルを入れる場所（DB フォルダ）を、自分で選べるようになった。
外付けディスクに研究用の DB を作る、症例集ごとに DB を分ける、といった使い方ができる。

| 操作 | 結果 |
|---|---|
| 環境設定 ＞ データ管理 ＞「新規 DB フォルダ…」で空のフォルダを選ぶ | 確認のあと、その DB に切り替えてアプリが再起動する |
| 「DB フォルダを開く…」で既存の DB フォルダを選ぶ | 同上 |
| 一覧の「切り替え」 | 最近使った DB・既定の DB に戻る |
| 「一覧から外す」 | 一覧から消えるだけ。フォルダの中身は消えない |

- 注意として書くこと:
  - 環境設定（テーマ・自局 AE など）はどの DB でも共通。XA の空間校正だけは DB ごと。
  - 選んだ DB が見つからないとき（外付けディスクを外したまま起動など）は、「再試行／既定の DB で起動／終了」を聞く。黙って空の DB を作らない。
  - 「;」を含むフォルダは選べない。ネットワーク上のフォルダは選べるが、ロックが不安定なことがあると警告する。
  - アンインストール時に（確認のうえ）消えるのはアプリのデータ領域（既定の DB を含む）だけ。自分で選んだ DB フォルダは残る（Windows のアンインストーラの定義で確認）。
  - この版で取り込んだ画像は、索引に相対パスで記録される。古い版に戻すと、その画像は開けない。
- 撮る画面の案: ①データ管理の DB フォルダ欄（既定だけ）②新規 DB に切り替えた後（2 行、使用中の札）。

## 検査を別の DB フォルダへコピー・移動（デスクトップ版・2026-10-11）

**利用者に伝えること**: Database tables の検査の行にある「別の DB へ…」で、検査を別の DB フォルダへコピー・移動できる。
レポート・ROI・位置合わせ・プラグインの記録・GLAM・XA の校正も一緒に運ぶ。

| 操作 | 結果 |
|---|---|
| 「別の DB へ…」→ 移し先を選ぶ →「コピーする」 | 移し先の受け取り箱（inbox）に置く。この DB には残る |
| 同じく「移動する」 | 運び終えて照合できたら、この DB から消す（ファイルも消す） |
| 移し先の DB に切り替える | 起動後に取り込み、右下に結果（取り込み・既にあり・失敗・衝突の件数）を一度だけ出す |

- 注意として書くこと:
  - 移し先に同じ画像（SOP）があれば取り込まない（上書きしない）。
  - 移し先にすでに中身の違うレポートや ROI があれば上書きせず、DB フォルダの `inbox/conflicts/` に残す。
  - ROI など患者単位の記録は、その患者の検査をすべて移したときに移し元から消える。一部だけのときはコピーされる。
  - 移動は、設定の「ファイルも削除」によらず移し元のファイルを消す（照合できたあとだけ）。
  - この PC の画面からしか使えない（LAN の他の端末からは呼べない）。
- 撮る画面の案: ①コピー・移動のダイアログ ②移し先に切り替えた後の右下の通知。

## デスクトップ版は別の PC のブラウザから開けなくなった（2026-10-11）

**利用者に伝えること**: デスクトップ版の画面と API は、その PC からだけ使えるようにした。
これまでは、同じ LAN の別の PC のブラウザから認証なしで開けてしまい、患者情報を読んだり書き換えたりできる状態だった。

- DICOM の受信（SCP）は従来どおり LAN から受けられる。PACS やモダリティからの送信には影響しない。
- 複数の PC や人で使いたい場合は、認証のある web 版を使う。
- 撮る画面は無い（注意書きだけ）。

## プラグイン導入の許可は確認ダイアログを通す・外部のページから操作できないようにした（2026-10-11）

**利用者に伝えること**: 環境設定 ＞ プラグイン の「導入を許可」を入れるとき、確認のダイアログが出るようになった。
「許可する」を押したときだけ変わる。あわせて、普通のブラウザで開いたほかのサイトから GRAPHY-Next を操作できないようにした。

- 撮る画面の案: 「導入を許可」を入れたときの確認ダイアログ（1 枚）。
