## 8. DICOM TLS のパスワード

テスト用のキーストアとトラストストア（PKCS12）を用意する。作り方の例（JDK の `keytool`）:
```bash
keytool -genkeypair -alias graphy -keyalg RSA -keysize 2048 -validity 30 -dname "CN=localhost" -storetype PKCS12 -keystore ks.p12 -storepass <キーストアのパスワード> -keypass <同じ>
keytool -exportcert -alias graphy -keystore ks.p12 -storepass <キーストアのパスワード> -file c.crt
keytool -importcert -noprompt -alias graphy -file c.crt -storetype PKCS12 -keystore ts.p12 -storepass <トラストストアのパスワード>
```

- [x] 8-1. 環境設定 ＞ DICOM 通信先 の TLS の欄で、TLS を有効にし、ポート・キーストア・トラストストアとパスワードを入れて保存する。
  OS のキーチェーンが使えない PC では「暗号化せずに保存しました」と警告が出る（Linux のキーリングが無い場合など）。
- [x] 8-2. 保存後、パスワードの欄は空欄で「設定済み」と出る。
- [x] 8-3. データの置き場の `settings.json` と `secrets.enc.json` を開き、**入れたパスワードの文字列がどこにも無い**。
  （キーチェーンが使えない PC では `settings.json` に平文で入るのが仕様）
- [x] 8-4. アプリを再起動すると、TLS の受信がそのポートで待ち受けている。自局を通信先に登録して C-ECHO（TLS あり）が成功する。
