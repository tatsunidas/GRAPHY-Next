# 施設の資料パネル（リンク集・参照カード）

施設が用意した資料（撮影プロトコル、院内規定、当直表、電話帳、IT 問い合わせなど）への入口を、メイン画面の「資料」節に出します。**内容は施設が管理する設定ファイル（JSON）1 つで配り**、GRAPHY-Next は枠と表示だけを持ちます。設定ファイルを置き換えるだけで、アプリを再起動せずに全端末の内容が変わります（共有フォルダに置いた場合）。

- 設定ファイルは**読むだけで、実行しません**。
- リンクは **https と mailto だけ**です（`http:`・`file:`・`javascript:`・相対パスは表示されません）。
- **患者情報を入れないでください。** この機能は、選択中の検査や電子カルテ連携の状態を一切参照せず、リンクに患者の情報を付けません。
- 画像・アイコン・埋め込み（iframe）は使えません。カードの本文はテキストだけで、HTML は解釈されません。
- 資料の正確さは施設の責任です。GRAPHY-Next は内容を保証しません。

## 設定ファイルの場所を決める

| 版 | 決め方 |
|---|---|
| デスクトップ版 | 環境設定 ▸ 施設の資料 ▸ 設定ファイル（.json）に、ファイルの場所を入れて保存します。共有フォルダ上のファイルも指定できます。 |
| Web 版（サーバー） | サーバーの管理者が、環境変数 `GRAPHY_FACILITY_CONFIG_PATH`（またはプロパティ `graphy.facility.config-path`）で決めます。画面からは変えられません（利用者が任意のサーバー上のパスを読ませられないようにするため）。 |

サーバー側の設定があるときは、デスクトップ版でも画面からは変えられません。

## 反映と、壊れたとき

- 1 秒ごとにファイルを見て、**書きかけを読まない**ため、大きさと更新時刻が 2 回続けて同じになってから読みます。画面は 2 秒ごとに問い合わせるので、ファイルを置き換えてから**数秒（おおむね 4 秒以内）**で内容が変わります。
- 内容に問題があると、**ファイル全体を採用せず、直前の有効な内容を表示し続けます**。環境設定 ▸ 施設の資料に、理由と場所（`groups[2].items[1].url` のような位置）が出ます。内容そのものは画面にもログにも出ません。
- 設定が無い（未設定）ときは、メイン画面に「資料」節を出しません。

## 上限

| 項目 | 上限 |
|---|---|
| ファイルの大きさ | 512 KiB（UTF-8、拡張子 `.json`） |
| グループ | 合計 200、入れ子は 3 段まで |
| 項目 | 合計 2,000 |
| 題名 | 200 文字、メモ 400 文字、カードの本文 4,000 文字 |

## ファイルの例

```json
{
  "schemaVersion": 1,
  "title": "放射線科 資料",
  "updatedAt": "2026-11-18",
  "contact": "mailto:rad-info@example.org",
  "groups": [
    {
      "id": "protocols",
      "title": "撮影プロトコル",
      "items": [
        { "type": "link", "title": "造影 CT プロトコル", "url": "https://intra.example.org/proto/ct", "note": "2026-10 改訂" }
      ],
      "groups": [
        {
          "id": "peds",
          "title": "小児",
          "items": [
            { "type": "link", "title": "鎮静の目安", "url": "https://intra.example.org/peds/sedation" }
          ]
        }
      ]
    },
    {
      "id": "phones",
      "title": "電話帳",
      "items": [
        { "type": "card", "title": "当直・緊急", "body": "放射線科 当直 内線 1234\nCT 室 内線 5678" },
        { "type": "link", "title": "IT 問い合わせ", "url": "mailto:it@example.org?subject=help" }
      ]
    }
  ]
}
```

| キー | 意味 |
|---|---|
| `schemaVersion` | 必須。いまは `1`。このアプリが知らない新しい版は読みません。 |
| `title`・`updatedAt` | 任意。節の見出しと、資料の更新日（文字列で表示）。 |
| `contact` | 任意。「管理者に連絡」の宛先（`mailto:` のみ）。 |
| `groups` | 必須。グループの配列。 |
| グループ `id`・`title` | 必須。`id` は英数字と `.` `_` `-`（64 文字まで）で、全体で重複不可。 |
| グループ `items`・`groups` | 任意。項目と、下位のグループ。 |
| 項目 `type` | `link`（`url` が必須）か `card`（`body` が必須。`url` は任意）。 |
| 項目 `id` | 任意。省略すると「グループ id.番号」になります。 |
| 項目 `note` | 任意。リンクの横に小さく出るメモ。 |

知らないキーは無視されます（将来の拡張で、古いアプリが読めなくなることを避けるため）。
