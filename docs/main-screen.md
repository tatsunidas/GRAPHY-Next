## 一覧の表示形式

一覧の見出しの右のボタンで、表／上下／左右／ツリーを切り替えられます（選んだ形式は保存されます）。

- 表: 検査の表の末尾にシリーズを出す従来の表示です（既定）。
- 上下・左右: 検査の表の下（右）に、シリーズの一覧を常に見せます。
- ツリー: 選んだ検査の行のすぐ下に、シリーズが子として開きます。同じ行をもう一度押すと畳みます。

上下・左右・ツリーでは、検査を選ぶと最初の画像シリーズが自動で開き、画像は下部のプレビューに出ます。
