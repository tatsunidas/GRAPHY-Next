# 電子カルテ連携（いま開いている患者を、2D ビューアで開く）

電子カルテが「いま開いている患者の ID」をローカルのファイル（CSV または bat）に書き出す運用のとき、そのファイルを GRAPHY-Next が監視し、**ID が変わった瞬間に、その患者の過去検査を PACS から取り込み、直近の検査を 2D ビューアで開きます**。デスクトップ版（standalone）で使えます。ファイルを読むだけで、書き換えも実行もしません。

## 流れ

1. 電子カルテが、患者を開くたびにファイルを書き換える。
2. GRAPHY-Next が 1 秒ごとにファイルを見る。書きかけを読まないよう、**大きさと更新時刻が 2 回続けて同じになってから**読む。
3. 読んだ ID が前回と違えば、PACS に C-FIND（患者 ID の完全一致）を出し、**直近の検査を先に**、残りの過去検査を続けて取り込む（全件。年数で絞ることもできる）。
4. 直近の検査が揃ったら、**自動で 2D ビューアに開く**（設定でオフにでき、そのときは［電子カルテの患者を開く］で開く）。

- 取り込んだ検査は、**翌日いっぱい**自動削除の対象から外れます。
- **患者が続けて切り替わったとき**は、最新の患者が勝ちます。前の患者の待ちは捨て、取り込み中だった 1 検査だけ終わらせて、残りは取りません。前の患者が、あとから開くことはありません。
- 同じ ID の書き直し（同じ患者でファイルが更新された）では、開き直しません。開き直したいときは［電子カルテの患者を開く］を押します。
- **起動した直後・有効にした直後・読み方の設定を変えた直後に読めた ID は、覚えるだけで開きません**（前の日の患者が、起動しただけで開くのを避けるため）。そのときの患者は［電子カルテの患者を開く］で開けます。

## 設定

環境設定 ▸ 電子カルテ連携。

| 項目 | 内容 |
|---|---|
| 監視するファイル | ファイル、またはフォルダ。フォルダなら、中で最後に更新された `.csv`・`.bat`・`.cmd`・`.txt` を読みます。 |
| 形式 | CSV／bat／拡張子で決める（`.bat`・`.cmd` は bat、それ以外は CSV）。 |
| 文字コード | UTF-8 か Shift_JIS。合わないときは「文字コードが合いません」と出し、化けた値を ID にしません。 |
| CSV の列・1 行目は見出し | ID の列を、見出しの名前か、1 から数えた番号で指定。**最後の行**を、いまの患者として読みます（追記でも上書きでも動きます）。見出しが無い CSV は、列を番号で指定します。 |
| bat の変数名 | `set 変数名=ID`（`set "変数名=ID"` や `@set` も可）の**最後の出現**を読みます。変数名の大文字小文字は区別しません。 |
| 自動で 2D ビューアに開く | オンで、ID が変わったら自動で開く。オフなら、取り込みだけ自動で行います。 |
| 取得元 PACS・取得の方式 | 「DICOM 通信先」に登録した相手から選びます。**既定値はありません**（施設の運用で決まるため）。C-MOVE は、PACS に自局の AE（受信口）を移動先として登録しておきます。C-GET は、検査が揃うまでビューアで開けません。 |
| 遡る年数 | 空なら全期間。 |
| 1 検査の待ち時間 | 大きな検査を取るときは長めに。 |

［いま読めるか確認］で、保存した設定のまま、ファイルから ID が読めるかを確かめられます（画面に出るのは、ID の先頭と末尾の数文字と文字数だけです）。

### ファイルの例

CSV（文字コード UTF-8、ID の列名 `患者ID`、1 行目は見出し）:

```
患者ID,氏名
P0001,山田
```

bat（変数名 `PATIENT_ID`）:

```
@echo off
set PATIENT_ID=P0001
```

## 開く

- メイン画面のツールバーの［電子カルテの患者を開く］、メニュー［ファイル］の同名の項目、トレイのメニュー（常駐を有効にしているとき）から、いまの患者の直近の検査を 2D ビューアで開けます。
- 取り込みがまだなら、取りに行ってから開きます。PACS に無い・取れなかったときは、**手元にあるその患者の最新の検査**を開き、それも無ければ理由を出します。
- 開くのは **PACS の直近の検査**です（手元に古い検査だけがあるときに、それを「直近」として開くことはしません）。
- メイン画面の下の状態バーに、「電子カルテ: 取り込み中 2/5」などの状態が出ます（患者 ID は出しません）。

## 安全のために

- **取り違えに注意してください。** 自動で開くので、電子カルテ側とビューア側の患者を、運用でも突き合わせてください。2D ビューアには患者名・患者 ID が出ます。オフにすれば、取り込みと［開く］だけで動きます。
- ファイルの中身は実行しません。**患者 ID として使えない内容は読みません**（空白・`&`・`|`・`<`・`>`・`^`・`%`・制御文字・65 文字以上）。読めないときは、理由のコードだけを出し、**中身は画面にもログにも出しません**。読めなくなっても、いまの患者は変えません。
- ファイルは通常のファイルで、64KB までです。許可していない拡張子は読みません。
- 患者 ID は画面に全文を出しません（先頭と末尾の数文字だけ）。

## つながらないとき

状態バーの表示と、環境設定 ▸ 電子カルテ連携の「状態」で、ファイルの状態と取り込みの状態を確認できます。PACS への検索が断られる・応答なしで切られるときは、DICOM 通信先の［通信テスト］で、通る探し方を確かめてください（[DICOM 通信](dicom-network.md)）。

- 電子カルテと PACS で患者 ID の形（先頭の 0、発行元）が違うと、「該当なし」になります（完全一致で探します）。
- 画面から開く要求は、外部から検査を開く入口（[外部から検査を開く](external-open.md)）と同じ経路を使います。
