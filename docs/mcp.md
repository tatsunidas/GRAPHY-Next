# 外部 AI クライアント（MCP）から使う

Claude Desktop・Claude Code などの外部 AI クライアントが、**起動中の GRAPHY-Next** を道具として使えるようにします。たとえば「今日の CT の検査を探して」「この検査のシリーズ構成を教えて」「この ROI の Radiomics 特徴量を計算して」と、AI に話しかけて頼めます。使うには、アプリで接続を許可し、AI クライアントに GRAPHY-Next の中継コマンドを登録します。研究用（Research Use Only）で、診断には使いません。

!!! warning "外部 AI クライアントは外部の送信先です"
    AI クライアントに返した内容は、そのクライアントを通じてクラウドの AI へ送られる可能性があります。既定では患者情報を伏せて返します。患者情報を返す設定は、そのことを理解したうえでオンにしてください。

## できること・できないこと

- **できること**: 検査・シリーズ・画像の一覧と構成、DICOM タグ（撮像条件など）、アルバム、2D ビューアの表示状態、ROI の計測値の読み取り。許可した場合は、Radiomics の特徴量の計算（元の画像・マスクは変更しません）。
- **できないこと**: 削除、データベースの管理、タグの編集、設定の変更、外部への送信（DICOM 送信・Query/Retrieve・書き出し）、匿名化。画像そのもの（画素）やキャプチャも返しません。
- 接続できるのは、**同じ PC で動いているアプリ**だけです（LAN からは使えません）。アプリが起動していないときは使えません。

## はじめかた

1. メイン画面の **環境設定**{.ui} ▸ **外部 AI クライアント（MCP）**{.ui} を開き、**外部 AI クライアントからの接続を受け付ける**{.ui} をオンにします。オンにするとき、アプリが確認のダイアログを出します。設定の詳しい説明は[環境設定](settings.md)にあります。
2. 同じ画面に **AI クライアントに登録するコマンド**{.ui} が表示されます（パッケージ版）。このコマンドを、AI クライアントの MCP サーバー設定に登録します（次の節）。
3. AI クライアントから最初に接続すると、アプリが「外部 AI クライアント『…』が接続を求めています」と確認します。心当たりがあれば［接続を許可］を選びます。クライアント名は相手の自己申告で、確認できません。拒否すると、アプリを再起動するまでその接続は受け付けません。確認は、アプリを起動するたびに最初の接続で出ます。

## AI クライアントへの登録

登録するコマンドは、インストール先の次の場所にあります（環境設定の画面にも表示されます）。

| OS | コマンド |
|---|---|
| Windows | インストール先の `resources\cli\graphy-mcp.cmd` |
| macOS | `GRAPHY-Next.app/Contents/Resources/cli/graphy-mcp` |
| Linux（deb） | `/opt/GRAPHY-Next/resources/cli/graphy-mcp` |

AppImage にはこのコマンドがありません（deb 版か、Windows・macOS 版を使ってください）。

### Claude Code

次のコマンドで登録します（Linux の例。`--scope` を省くと、今のプロジェクトだけに登録されます。すべてのプロジェクトで使うなら `--scope user`）。

```
claude mcp add graphy -- /opt/GRAPHY-Next/resources/cli/graphy-mcp
```

登録すると、設定ファイル（`.mcp.json` など）に次の形で記録されます。

```json
{
  "mcpServers": {
    "graphy": {
      "type": "stdio",
      "command": "/opt/GRAPHY-Next/resources/cli/graphy-mcp",
      "args": [],
      "env": {}
    }
  }
}
```

### Claude Desktop

設定ファイル `claude_desktop_config.json`（Claude Desktop の設定 ▸ 開発者 から開けます）の `mcpServers` に、同じ形で足します。Windows ではパスの `\` を `\\` と書きます。

```json
{
  "mcpServers": {
    "graphy": {
      "command": "C:\\Users\\<ユーザー名>\\AppData\\Local\\Programs\\GRAPHY-Next\\resources\\cli\\graphy-mcp.cmd",
      "args": []
    }
  }
}
```

!!! note "Claude Desktop の設定例は、実機で確かめていません"
    Claude Desktop の設定の書き方は、Claude Desktop の公式の説明に従った一般的な形です。GRAPHY-Next 側のコマンドと接続（stdio）は、Claude Code と、検査用の MCP クライアントで動作を確かめています。インストール先のパスは、環境設定の画面に表示されたものを使ってください。

## 使えるツール

AI クライアントには、次のツールが見えます。ツールの使い分けは AI が行うので、普段は意識する必要はありません。

| ツール | 内容 |
|---|---|
| `get_status` | アプリの版とモード |
| `list_albums` / `list_album_studies` | アルバムの一覧と、アルバムに入っている検査 |
| `search_studies` | 検査の検索（モダリティ・検査日。患者名・患者 ID での絞り込みは、患者情報の設定がオンのときだけ） |
| `list_series` / `list_instances` | 検査のシリーズ一覧／シリーズの画像一覧 |
| `get_series_layout` | シリーズの 5D（Z/C/T）の配置 |
| `get_tags` | 画像の DICOM タグ（撮像条件など。患者情報のタグは、設定がオンのときだけ） |
| `list_compute_jobs` | 計算ジョブの一覧と状態 |
| `get_viewer_state` | 開いている 2D ビューアの表示状態（モダリティ・スライス位置・窓幅/窓位・向き・倍率）。2D ビューアが開いていないときは `no-viewer` |
| `get_measurements` | 2D ビューアに描いた ROI の計測値（最大 50 件）。AI クライアントごとに、最初の 1 回、アプリが確認を出します |
| `radiomics_submit` / `radiomics_status` | Radiomics の特徴量の計算を投入し、状態と結果を見る（**解析の実行（Radiomics の特徴量の計算）を許可する**{.ui} がオンのときだけ） |

## 患者情報の扱い

- **既定（患者情報を返す設定がオフ）**: 患者名・患者 ID・生年月日・受付番号・紹介医などを返しません。検査・シリーズ・画像の識別子は、この接続のあいだだけ有効な仮の札（`st_…`・`se_…`）にして返し、AI が次のツールを呼ぶときにアプリが元の値に戻します。患者は `S001`・`S002` のように区別します。DICOM タグは、撮像条件など患者情報を含まないものだけ返します。
- **患者情報を返す設定がオン**: 実際の値を返します。返した内容は、AI クライアントを通じてクラウドの AI へ送られる可能性があります。**患者情報（氏名・患者 ID・生年月日・識別子の実値）を返す**{.ui} をオンにするときは、アプリが確認を出します。
- 画像そのもの（画素）は、どちらの設定でも返しません（画像に焼き込まれた患者情報があり得るため）。

## 記録

接続と呼び出しは、アプリのユーザーデータフォルダ（Windows は `%APPDATA%\graphy-next-desktop`、macOS は `~/Library/Application Support/graphy-next-desktop`、Linux は `~/.config/graphy-next-desktop`）の `mcp-audit.jsonl` に記録されます（時刻・ツール名・結果・返したバイト数・患者情報の設定・クライアント名）。引数と結果の本文は記録しません。

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 「GRAPHY-Next が起動していないか、設定で MCP 接続がオフです」と返る | アプリを起動し、**外部 AI クライアントからの接続を受け付ける**{.ui} がオンか確かめます。アプリを起動しなおした後は、AI クライアントを再起動すると確実です。 |
| 「GRAPHY-Next 側で接続が拒否されました」と返る | 最初の接続の確認で［拒否］を選んでいます。アプリを再起動すると、もう一度確認が出ます。 |
| ツールの一覧が空のまま | 最初の接続の確認が出ていないか、アプリの画面を確かめます。答えると、一覧が自動で更新されます。 |
| `no-viewer` と返る | 2D ビューアが開いていません。`get_viewer_state`・`get_measurements` は、2D ビューアが開いているときだけ使えます。 |
| `radiomics_submit` が見えない | **解析の実行（Radiomics の特徴量の計算）を許可する**{.ui} をオンにします。 |

## 知っておいてください

- この機能は、同じ PC の中だけで動くよう作られています。ただし、アプリの内部の API（`127.0.0.1`）は、同じ PC で動く他のプログラムからは認証なしで呼べます（デスクトップ版の仕様で、MCP を使う・使わないに関わらず同じです）。共用の PC では、利用者を分けるか、使わないでください。
- 患者情報を返す設定をオンにして使うときは、所属機関の規則（外部サービスへの患者情報の送信）を確認してください。
