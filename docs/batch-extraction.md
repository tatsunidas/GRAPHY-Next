# 一括抽出と無人実行

アルバムにある複数の症例の ROI 特徴量（または VOI 統計）を、まとめて抽出して 1 つの表にします。研究用（Research Use Only）で、診断には使いません。

## 画面から

アルバムを選び、**特徴量を一括抽出…**{.ui} を押します。

1. アルバムの SEG から、（元画像, セグメント）の組が作られます。元画像が決まらない組は、元画像を選ぶまで対象に入りません。
2. 設定（離散化・特徴量の族・QC など）と、出力のファイル名の接頭辞を決めます。
3. 実行すると、症例ごとの行を持つ 1 つの表（CSV）と、定義表・設定・処理の定義・被験者の対応表が書き出されます。患者名は入りません。患者 ID は、被験者の対応表（共有しないファイル）にだけ入ります。

### 処理の定義

設定を **定義を保存**{.ui} で JSON に保存できます。**定義を読み込む…**{.ui} で読み込むと、同じ設定を再現できます。定義には SHA-256 が入り、改変や破損があると読み込めません。表の `Provenance_SpecSha256` 列に、実行に使った定義の SHA-256 が入ります。

### 定義の一覧（順に実行）

**定義の一覧（順に実行）**{.ui} に保存した定義を並べると、上から順に実行して、定義ごとに表を書き出します。**定義を追加…**{.ui} で定義のファイルを加え（複数選べます）、**一覧を順に実行**{.ui} を押します。失敗した定義があっても残りは続けます。

## コマンドラインから（無人実行）

画面を開かずに、同じ処理を実行できます。夜間のバッチや、決まった設定の定期実行に使います。インストール版に起動用のコマンドが入っています。

| OS | コマンド |
|---|---|
| Windows | インストール先の `resources\cli\graphy-batch.cmd` |
| macOS | `GRAPHY-Next.app/Contents/Resources/cli/graphy-batch` |
| Linux（deb） | `/opt/GRAPHY-Next/resources/cli/graphy-batch` |

```
graphy-batch --album <アルバム名|ID> --spec a.json [--spec b.json …] --out <出力フォルダ> [--recompute] [--report <ファイル>]
```

- `--album`: アルバムの名前または ID。同じ名前が複数あるときは ID で指定します。
- `--spec`: 保存した処理の定義。複数指定すると、指定した順に実行します。定義ごとに出力の接頭辞が違うことが必要です。
- `--out`: 出力フォルダ。定義ごとのファイルと、結果の報告（`batch-cli-report.json`）が入ります。
- `--recompute`: 計算済みの結果（キャッシュ）を使わず、計算し直します。
- `--data-dir`: データの置き場所（通常は指定しません。アプリと同じ場所を使います）。

!!! warning "アプリを閉じて実行してください"
    画面のアプリが同じデータベースを開いている間は実行できません（終了コード 5）。アプリを閉じてから実行します。

実行すると、画面を出さずに内部のサーバーを起動し、終わったら止めます。起動には 30 秒ほどかかります。

### 終了コード

| コード | 意味 |
|---|---|
| 0 | すべての定義が完了した |
| 1 | 失敗した定義がある（残りは実行されます） |
| 2 | 失敗はないが、QC で止まった定義、または元画像が決まらず実行しなかった組がある |
| 3 | 引数または定義の誤り（定義の SHA-256 が合わない、アルバムが無いなど）。1 つでも不正なら何も実行しません |
| 4 | 内部のサーバーが起動しない、接続できないなどの例外 |
| 5 | 画面のアプリなどがデータベースを使用中 |

元画像が複数あって決まらない組は、無人では選べないので実行しません。結果の報告（`batch-cli-report.json`）に、実行しなかった組が書かれます。画面で元画像を選んで実行してください。

!!! note "Linux の AppImage"
    AppImage 版には起動用のコマンドが入っていません。`--appimage-extract` で展開するか、deb 版を使ってください。
