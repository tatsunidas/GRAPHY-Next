## 受信時の匿名化（スタンドアロン）

環境設定 ▸ DICOM 通信先 ▸「受信時の匿名化」で有効にすると、C-STORE・C-GET で受け取った画像を、保管庫に入れる前に匿名化します（原本は保管しません）。患者 ID と UID は元の値と鍵から決まる仮名になり、同じ患者・同じ検査は別の日・別の送信でも同じ仮名にまとまります。次の受信から効き、再起動は要りません。

- 焼き込み文字の恐れのある画像（BurnedInAnnotation=YES、または属性が無い US・SC・ES・XC・GM・OT）と、匿名化に失敗した画像は受け取らず、送信側にエラーを返します。画素の文字の消去は受信時には行いません。
- 仮名の鍵は初回の受信で作られます。失うと同じ患者でも別の仮名になるため、「鍵を書き出す」で保管してください。
- メイン画面の下の状態バーに、有効なときだけ「受信時の匿名化: オン（受付 n / 拒否 m）」を表示します。

## 他端末からの検索に応える（スタンドアロン）

環境設定 ▸ DICOM通信 ▸「他端末からの検索」で「他端末からの検索を受け付ける」をオンにしてアプリを再起動すると、他の DICOM 端末が、この端末に保管したスタディを C-FIND で検索できます。**既定はオフ**です。患者名・患者 ID・検査日などが相手に渡るので、使うネットワークと相手を確かめてからオンにしてください。

- 応えるのは、相手先の一覧に登録した AE タイトルからの要求だけです。「登録外の相手にも応える」をオンにすると、すべての相手に応えます（閉じたネットワークでだけ使ってください）。こちらは再起動なしですぐに効きます。
- Patient Root と Study Root の問い合わせに、患者・スタディ・シリーズ・画像のレベルで応えます。ワイルドカード（`*` `?`）、日付の範囲（`20260101-20260331`）、UID のリスト（`\`区切り）で絞れます。PatientName は大文字小文字を区別せず、その他は区別します。
- 戻す値は、保管庫の索引にあるもの（患者・検査日・説明・アクセッション番号・モダリティ・シリーズ番号・枚数など）です。索引に無い属性（StudyTime・StudyID・ReferringPhysicianName など）は、要求されても空で返し、検索キーに指定されても無視します。
- 画像の取得（C-MOVE）には、まだ対応していません。
- AE タイトルは相手の自己申告で、なりすませます。本人確認が要る環境では、TLS（相互認証）も併用してください。応えた検索と、拒否した要求は、相手の AE タイトルとともにログに残ります。
