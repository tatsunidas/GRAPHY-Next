## 受信時の匿名化（スタンドアロン）

環境設定 ▸ DICOM 通信先 ▸「受信時の匿名化」で有効にすると、C-STORE・C-GET で受け取った画像を、保管庫に入れる前に匿名化します（原本は保管しません）。患者 ID と UID は元の値と鍵から決まる仮名になり、同じ患者・同じ検査は別の日・別の送信でも同じ仮名にまとまります。次の受信から効き、再起動は要りません。

- 焼き込み文字の恐れのある画像（BurnedInAnnotation=YES、または属性が無い US・SC・ES・XC・GM・OT）と、匿名化に失敗した画像は受け取らず、送信側にエラーを返します。画素の文字の消去は受信時には行いません。
- 仮名の鍵は初回の受信で作られます。失うと同じ患者でも別の仮名になるため、「鍵を書き出す」で保管してください。
- メイン画面の下の状態バーに、有効なときだけ「受信時の匿名化: オン（受付 n / 拒否 m）」を表示します。

## 他端末からの検索・取得に応える（スタンドアロン）

環境設定 ▸ DICOM通信 ▸「他端末からの検索・取得」で「他端末からの検索・取得を受け付ける」をオンにしてアプリを再起動すると、他の DICOM 端末が、この端末に保管したスタディを C-FIND で検索し、C-MOVE で取り出せます。**既定はオフ**です。患者名・患者 ID・検査日などと画像そのものが相手に渡るので、使うネットワークと相手を確かめてからオンにしてください。

- 応えるのは、相手先の一覧に登録した AE タイトルからの要求だけです。「登録外の相手にも応える」をオンにすると、すべての相手に応えます（閉じたネットワークでだけ使ってください）。こちらは再起動なしですぐに効きます。
- Patient Root と Study Root の問い合わせに、患者・スタディ・シリーズ・画像のレベルで応えます。ワイルドカード（`*` `?`）、日付の範囲（`20260101-20260331`）、UID のリスト（`\`区切り）で絞れます。PatientName は大文字小文字を区別せず、その他は区別します。
- 戻す値は、保管庫の索引にあるもの（患者・検査日・検査時刻・検査 ID・紹介医・説明・アクセッション番号・モダリティ・シリーズ番号・枚数など）です。検査時刻は `1200-1300`・`1200-`・`-0930` のような範囲で絞れます（桁数の少ない端は、その桁数までで比べます）。紹介医（ReferringPhysicianName）は大文字小文字を区別しません。索引に無い属性（InstitutionName など）は、要求されても空で返し、検索キーに指定されても無視します。検査時刻・検査 ID・紹介医は、このバージョンへ更新した直後に、保管済みの画像のヘッダから自動で読み込みます（起動後の背景処理）。読み込みが終わるまでは、これらのキーでの検索に当たらないスタディがあります。
- 取得（C-MOVE）は Patient Root と Study Root で、患者・スタディ・シリーズ・画像のレベルで応えます。UID（患者レベルは患者 ID）を指定して取り出し、`*` などのワイルドカードは解釈しません（一致なし＝0 件で成功）。
- 画像の送り先（MoveDestination）は、**相手先の一覧に登録した AE だけ**です。「登録外の相手にも応える」をオンにしても変わりません。未登録の送り先は 0xA801 で断ります。TLS を要する送り先に TLS の設定が使えないときは、平文では送らず失敗にします。
- 圧縮して保管した画像（可逆の JPEG-LS・JPEG 2000）は、送り先が受けるならそのまま送り、受けないときは復号して Explicit VR Little Endian で送ります。ファイルを読めない画像は失敗に数え、残りは送ります（結果は一部失敗）。途中の中止（C-CANCEL）に対応しています。
- AE タイトルは相手の自己申告で、なりすませます。本人確認が要る環境では、TLS（相互認証）も併用してください。応えた検索・取得と、拒否した要求は、相手の AE タイトルとともにログに残ります。

## 同じ LAN の機器を見つける（mDNS）

- **探す**: 環境設定 ▸ DICOM 通信先の［ネットワークで探す］を押すと、約 3 秒、同じ LAN で自分の AE を知らせている DICOM 機器（mDNS の `_dicom._tcp`）を探して一覧に出します。自分自身は出ません。見つからなければ「見つかりませんでした」と出ます。一覧の［追加］を押したときだけ、リモート AE の行に入ります（保存は従来どおり［保存］。押さない限り何も保存されません）。同じ AE タイトルがすでにあれば、上書きするかを確かめます。追加したあとは、行の［疎通確認］（C-ECHO）で確かめてください。相手が TLS を受けるときは、TLS のポートで TLS ありとして入ります（使えなければ行で外せます）。同じ機器が有線・無線の両方で見えるときは 1 台にまとめ、アドレスを選べます。
- **知らせる**: 環境設定 ▸ DICOM通信 ▸「ネットワーク上で自分の AE を知らせる」をオンにしてアプリを再起動すると、DICOM 受信（SCP）が動いている間、AE タイトル・ポート・TLS の有無・版を同じ LAN に知らせます。**既定はオフ**です。患者情報や画像は流れません。知らせると、同じ LAN の機器がこの端末を送信先として見つけやすくなります。受信側には送信元の許可リストが無いので、信頼できる LAN でだけ使ってください。
- 見つかった機器は**認証されていません**（同じ LAN の誰でも名前を名乗れます）。送信先は確かめてから追加してください。
- 実装は OS で違います（Linux・Windows は JmDNS、macOS は OS 標準の `dns-sd`）。ルータや Wi-Fi が mDNS を通さない環境、macOS のローカルネットワークの許可、Windows のファイアウォール（UDP 5353）の影響で、見えないことがあります。
