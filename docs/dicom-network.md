## 受信時の匿名化（スタンドアロン）

環境設定 ▸ DICOM 通信先 ▸「受信時の匿名化」で有効にすると、C-STORE・C-GET で受け取った画像を、保管庫に入れる前に匿名化します（原本は保管しません）。患者 ID と UID は元の値と鍵から決まる仮名になり、同じ患者・同じ検査は別の日・別の送信でも同じ仮名にまとまります。次の受信から効き、再起動は要りません。

- 焼き込み文字の恐れのある画像（BurnedInAnnotation=YES、または属性が無い US・SC・ES・XC・GM・OT）と、匿名化に失敗した画像は受け取らず、送信側にエラーを返します。画素の文字の消去は受信時には行いません。
- 仮名の鍵は初回の受信で作られます。失うと同じ患者でも別の仮名になるため、「鍵を書き出す」で保管してください。
- メイン画面の下の状態バーに、有効なときだけ「受信時の匿名化: オン（受付 n / 拒否 m）」を表示します。
