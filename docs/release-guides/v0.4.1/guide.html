DB フォルダを
使い分ける

検査の索引と画像をまとめた「DB フォルダ」を、研究ごと・外付けディスクなどに分けて使えるようになりました。検査を別の DB フォルダへコピー・移動することもできます。あわせて 2D・MPR などの細かな改良が入っています。

DB フォルダ コピー・移動 ROI のロック

使い方（デスクトップ版のみ）

  1. 01

    環境設定 ＞ データ管理 ＞ DB フォルダ新しく作る・既存のものを開く・一覧から切り替える。切り替えるとアプリが再起動します

  2. 02

    DB テーブル管理で検査の「別の DB へ…」コピーか移動を選ぶ。移し先は、次にその DB を開いたときに取り込まれます

  3. 03

    環境設定（表示・通信先など）はどの DB でも共通DB フォルダの中には、検査の索引と DICOM ファイルだけが入ります

研究用です。診断には使わないでください。データ: TCIA HCC-TACE-Seg（Moawad et al., 2021）CC BY 4.0　doi.org/10.7937/TCIA.5FNA-09241 / 7

STEP 1 / 環境設定 ＞ データ管理 ＞ DB フォルダ

DB フォルダを作る・開く・切り替える

  1. 1

    いま使っている DB（使用中）。最初からある DB は「既定」

  2. 2

    前に使った DB。「切り替え」で再起動して切り替わります

  3. 3

    空のフォルダを選び、新しい DB を作る

  4. 4

    別の PC で作った DB・複製した DB を開く

画像はフォルダからの相対パスで記録します。フォルダごと複製・移動しても開けます。

外付けディスクが見つからないときは、再試行・既定の DB で起動・終了を選べます。

研究用です。診断には使わないでください。2 / 7

STEP 2 / DB テーブル管理 ＞ 検査の「別の DB へ…」

検査を別の DB フォルダへコピー・移動する

  1. 1

    移し先の DB フォルダ。一覧に無いものは「フォルダを選ぶ…」から

  2. 2

    方法。コピーは今の DB にも残し、移動は運び終えて照合できたら今の DB から消します

  3. 3

    「コピーする」（移動のときは「移動する」）

レポート・ROI・位置合わせ・プラグインの記録なども一緒に運びます。移し先に同じものがあれば、上書きせずに残します。

移し先の DB に切り替えたときに取り込まれ、右下に件数が出ます。

研究用です。診断には使わないでください。データ: TCIA HCC-TACE-Seg CC BY 4.03 / 7

STEP 3 / 2D ビューアの改良

Cobb 角・ROI のロック・画像のコピー

  1. 1

    ROI メニューの Cobb 角。離れた 2 本の線のなす角を測ります

  2. 2

    ロック（ROI マネージャの 🔒）。ロックした ROI は動かず、Delete・ゴミ箱・全消去でも消えません

  3. 3

    📋 で表示中の画像をクリップボードへコピー（ROI・文字は含みません）。Word などにそのまま貼れます

拡大レンズ（4×）: 画像メニューで選び、左ボタンを押している間だけ、カーソルのまわりを 4 倍で表示します。

ロックと表示・非表示は保存され、開き直しても残ります。

研究用です。診断には使わないでください。データ: TCIA HCC-TACE-Seg CC BY 4.04 / 7

STEP 4 / MPR Viewer

MPR の十字線が表示されるようになりました

各面に、ほかの 2 面の位置が線で出ます。画像をクリックすると、3 面がその点へ移ります。

以前の版では、色の渡し方の誤りで十字線が描かれていませんでした（クリックで移る操作は動いていました）。

線の色は 環境設定 ＞ 表示 ＞ MPR の「十字線の色」で、面ごとの色（Axial 緑・Sagittal 黄・Coronal 青）か単色（色も選べる）を選べます。

設定を変えたら、MPR を開き直すと反映されます。

研究用です。診断には使わないでください。データ: TCIA HCC-TACE-Seg CC BY 4.05 / 7

そのほかの改良

操作が少し便利になったところ

どこで何ができるようになったか
一覧画面エクスプローラー・Finder からファイルやフォルダをドラッグ＆ドロップして取り込める（デスクトップ版）
キーボードF で全画面（どの窓でも。Esc でも戻る）。2D ビューアで W / P / Z / L / A / R / E を押すと、W/L・移動・拡大・長さ・角度・矩形・楕円に切り替わる
2D ビューアの ROI選択中の ROI は内側をドラッグして移動できる。Ctrl（Mac は ⌘）＋クリックで複数選択し、表示中のスライスの選択中 ROI をまとめて動かせる
Fusion操作バーの「重ね方」で差分・乗算を選べる。表示上の合成で、画素値（HU・SUV）の引き算ではない
3D ビューア環境設定 ＞ 表示 ＞ 3D ビューアで背景色を変えられる（VR・MIP・Ortho・Slab）
NIfTI の取り込み整数でない値（ADC・T1 マップなど）を 32 bit float の Parametric Map として取り込み、単位を選べる。2D の W/L・MPR・3D・テクスチャでも扱える
起動の表示スプラッシュの段階を「部品の準備・データベース・機能の準備」に分け、何を待っているかが分かるようにした
画像の削除ファイルも消す設定のとき、消した画像の ROI・位置合わせ・プラグインの記録なども片付ける（レポートは残す）
研究用です。診断には使わないでください。6 / 7

直したこと・安全性

気付かないうちに起きていたことを直しました

どこで直したこと
接続の制限デスクトップ版の HTTP を、その PC（127.0.0.1）からだけ受けるようにした。ブラウザ経由の不正な呼び出しも塞いだ
DICOM TLSTLS のパスワードを OS の鍵束に保存し、画面の API でも返さないようにした（鍵束の無い環境では、警告を出して従来どおり保存）
プラグインプラグインの導入の同意を、本体の確認の窓からしか変えられないようにした
取り込み失敗しても元のファイルを失わない。空のフォルダや作業用のフォルダを残さない
患者 ID の変更ROI などの記録も新しい患者 ID へ運ぶ
DSAAlt＋↑ / ↓（マスクの上下のシフト）が効いていなかったのを直した
ROI開き直すとロックが外れて見えた・表示の切り替えが保存されなかったのを直した。双方向計測を ImageJ 形式で書き出すと矩形になっていたのを直した
再起動（Linux）AppImage で DB フォルダの切り替えなどの再起動が失敗していたのを直した

変更の全体はリリースノート（GitHub の Releases）にあります。

研究用です。診断には使わないでください。7 / 7
