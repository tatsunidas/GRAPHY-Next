# 操作の手順（やりたいことから探す）

このページは「〜したい」から、データベースウィンドウでの操作を番号で並べたものです。各ボタンや項目の詳しい説明は [データベースウィンドウ](main-screen.md) を見てください。

## 患者名で検査を探して 2D Viewer で開く

1. 左の検索パネルの **患者名**{.ui} に、名前の一部を入れます。
2. **検査日**{.ui} を確かめます。今日の検査なら **今日**{.ui}、日付が分からなければ **全期間**{.ui} を押します（起動直後の既定は今日です）。
3. **検索**{.ui} を押します。
4. **スタディ一覧**{.ui} で目的の検査の行を押します。その検査のシリーズが表の下に出ます。
5. 開きたいシリーズの行を押します。下のプレビューに画像が出るので、ここで中身を確かめられます。
6. ツールバーの **2D Viewer**{.ui}（またはメニューの **画像**{.ui} › **2D Viewer**{.ui}）を押します。別のウィンドウで開きます。

## モダリティ（CT・MR など）と検査日で絞って開く

1. **モダリティ**{.ui} の **選択…**{.ui} から CT や MR を選びます。
2. **検査日**{.ui} の下のボタン（**今日**{.ui}・**昨日**{.ui}・**1週間**{.ui}・**全期間**{.ui}）で期間を入れます。
3. **検索**{.ui} を押します。
4. 検査の行 → シリーズの行を押し、ツールバーの **2D Viewer**{.ui}・**3D Viewer**{.ui}・**MPR Viewer**{.ui} のいずれかで開きます。

## 取り込んだ検査が一覧に出ないとき

1. **検査日**{.ui} が今日になっていないか見ます（アプリを起動した直後の既定は今日です）。
2. **全期間**{.ui} を押してから **検索**{.ui} を押します。
3. 取り込み直後に出ていた一覧から戻ったときも同じです。**検索条件の一覧に戻る**{.ui} を押した後は、検索パネルの条件（**検査日**{.ui} など）で探す一覧になります。

## 3D Viewer で開く

1. 検査（またはシリーズ）の行を押して選びます。
2. ツールバーの **3D Viewer**{.ui}、またはメニューの **画像**{.ui} › **3D Viewer**{.ui} を押します。使い方は [3D ビューア](viewer3d.md) を見てください。

## 検索条件を保存する・呼び出す

- 保存: 検索パネルに条件を入れて **条件を保存…**{.ui} を押します。
- 呼び出し: **保存した検索**{.ui} から選びます。

## DICOM のフォルダを取り込む

1. メニューの **ファイル**{.ui} › **インポート**{.ui}（ツールバーの **インポート**{.ui} でも同じです）。
2. DICOM ファイルが入ったフォルダを選びます。サブフォルダの中も取り込まれます。
3. 取り込んだ検査は、検索条件を使わずにそのまま **スタディ一覧**{.ui} に出ます。

## URL から取り込む

- メニューの **ファイル**{.ui} › **URL から取り込む…**{.ui} を選びます。

## 一覧の見え方を変える・まとめて選ぶ

- 列を足す: **スタディ一覧**{.ui} の見出しの右の **列**{.ui} を押し、DICOM の辞書（キーワードまたはタグ）から選びます。
- 表示形式: 見出しの右のボタンで **表**{.ui}・**上下**{.ui}・**左右**{.ui}・**ツリー**{.ui} を切り替えます。
- 複数の検査を選ぶ: 行の左のチェックを付けます（見出しのチェックで全選択）。
- プレビューを畳む: **プレビューを隠す**{.ui} を押します。

## このページに手順が無い機能

**匿名化**{.ui}・**タグ抽出**{.ui}・**タグ表示**{.ui}・**シリーズ抽出**{.ui}・**レポート**{.ui}・**レポート管理**{.ui} の手順は、まだ説明を作っていません。
