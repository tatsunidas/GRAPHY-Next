## このデータで「確認できること / できないこと」

**できる**
- A1: フレーム展開・シネ再生・実測 fps・Frame/Run スライダーの提示・ホイール送り・Grid（フレーム一覧）
- A2: 対数変換（`PixelIntensityRelationship = LIN`）経路の DSA、マスク自動選択、ピクセルシフト
- A3: **未校正（P7）に落ちて px 表示になること**と、カテーテル校正（C2）で mm になること
- A4: QCA が動くこと（**数値の正しさは別**。下記）

- **A5b（LV モノプレーン）**: `0009.DCM` で ED/ES 選択・輪郭・**EF** まで。
  EF はスケール不変（体積が長さの 3 乗 → 比で倍率が消える）なので、**空間校正が無くても数値を検証できる**。
  ⚠️ ただし **Kennedy 補正（`V = 0.928·V_AL − 3.8 mL`）はアフィンなのでスケール不変ではない**。
  未校正データで補正版 EF を出すと嘘になる。設計 §9.2.1。

**できない**
- A3 の **P1〜P5 の経路**（`PixelSpacing` / `ImagerPixelSpacing` / SID/SOD がこのデータに無い）。
  特に **P3'（`PixelSpacing` が `ImagerPixelSpacing` と同値＝未校正）の降格**は踏めない。
- A4 の **精度検証**（真値が無い）。`bench/` の GNBP-XA ファントム（設計 §16.3 / A4b）が要る。
- **A6（3D QCA）は 6 本すべてで不可**。理由は 3 つあり、どれ 1 つでも致命的:
  1. 2 方向が揃う唯一の組（`0003`/`0004`）に**造影血管が写っていない**
  2. 造影がある組（`0009`/`0012`）は**角度が完全に同一**（視差ゼロ＝三角測量が退化）
  3. **全 6 本に SID/SOD が無い**ので、そもそも射影行列が組めない
  → 精度は `bench/` の GNBP-XA-3 でしか測れない（設計 §21.3）。
  なお `0003`/`0004` は「同一患者を 71.8° 離れた 2 方向から撮った実データ」ではあるので、
  **ワイヤ・バルーンを対象にした対応付け UI（エピポーラ線・手動マッチング）の実データ試験**には使える。
  SID/SOD を仮定値で埋めることになるため、**精度は一切主張できない**。
- **A5c（LV バイプレーン）**: 同時 2 方向のデータが 1 本も無い。
- A9（RDSR がこのデータに無い）。
- A5a（QVA）: 末梢・脳血管のデータが無い（いずれも冠動脈・左室）。
